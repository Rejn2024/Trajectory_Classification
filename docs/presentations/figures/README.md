# Introduction and forecasting slide images

These standalone PNGs can be inserted into another presentation. Each uses the
same content as the corresponding slide in the [PDF](../presentation.pdf) and
[offline HTML deck](../presentation.html). They require no notebook runtime,
model files, dataset downloads or network connection to display.

| Slide | Image | Content |
| --- | --- | --- |
| 1 | [slide_01.png](slide_01.png) | Multi-pilot training as preparation for the forecasting dataset |
| 17 | [slide_17.png](slide_17.png) | Observer, prediction target, dataset partitions and shared forecasters |
| 18 | [slide_18.png](slide_18.png) | Actual validation forecast and the meaning of position error |
| 19 | [slide_19.png](slide_19.png) | Population errors, reference methods and practical position tolerances |
| 20 | [slide_20.png](slide_20.png) | Five-second position and velocity errors across all ten pilots |
| 21 | [slide_21.png](slide_21.png) | Motion interpretation, catalogue skills and evaluation scope |

The forecasting figures report **development validation**, with the final test
partition reserved. The slide 18 example is selected at the pooled median
five-second Transformer error; the overall means on slides 19 and 20 instead
weight episodes equally. Full evidence and supplementary notes are included in
the [presentation report](../README.md).
